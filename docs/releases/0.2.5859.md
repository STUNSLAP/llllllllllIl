# CodeDB 0.2.5859

Fixes `codedb context` reporting `semantic lane: unavailable` with the default hosted configuration.

## Hosted semantic retrieval

The hosted default model id is now `codedb-hosted-v1`. Local ANN sidecars built by earlier releases are rebuilt once in the background the first time a hybrid query sees them; the bounded exact rerank serves that request meanwhile. Custom endpoints and explicit model overrides are unchanged.

Local retrieval, the watcher, and the installer are unchanged.
