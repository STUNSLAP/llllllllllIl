# CodeDB 0.2.5860

Faster hosted semantic index builds.

## Hosted semantic retrieval

`codedb semantic-index` now sends 100-item batches with eight requests in flight by default. `CODEDB_SEMANTIC_INDEX_CONCURRENCY` still overrides the concurrency (1-8).

Index builds wait out hosted rate limits with a doubling backoff capped at 30 seconds, instead of failing after a few quick retries. Interactive `codedb context` calls are unchanged and still fall back to local results immediately.

Local retrieval, the watcher, and the installer are unchanged.
